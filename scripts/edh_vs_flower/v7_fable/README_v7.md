# v7_EdH_Fable — EdH スピンテクスチャ動力学を「実験と同じ観測量」から再構成する

目的: v6 EdH 完全シミュレーション（96³・f64・全格子, `edh_v6_psi13.jld2`）を真値とし、
実機で取得可能な観測量（傾斜SG吸収撮像のピクセルデータ）だけを入力として
スピンテクスチャの時間発展を再構成し、その精度と原理限界を定量化する。
EdH vs Flower 弁別は対象外（EdH 単独）。

## 幾何（ロック済・ユーザー決定 2026-07-02）

- カメラ視線 = 実験室 **ŷ**（横から撮像）。吸収撮像はカラム積分 `∫dy`。
- SG 分離軸 = 実験室 **ẑ**（重力方向の勾配で m 雲が縦に分離）。
- 画像平面 = **(x, z)**。画像ピクセル = 計算グリッド（96×96、間引き・フロアなし）。

### 量子化軸の傾けはスピン空間の回転「のみ」である（導出）

撮像前に磁場を断熱回転して量子化軸を傾ける。スピンは局所的に B に追従するので、
全ボクセルに一様なスピン回転 `R_a(β)=exp(−iβF_a)` が ψ に作用するのと等価:
`ψ(r) → R ψ(r)`。**空間座標には何も起きない**。従って測定される占有像は

```
N_m^(a,β)(x,z) = ∫dy |[R_a(β) ψ]_m(r)|²
```

視線（積分方向）は常に ŷ のまま。傾斜角を何個増やしても増えるのは
**スピン射影軸 n(β) の走査情報**であり、**空間投影方向は 1 本のまま**。
ゆえに y 方向（視線方向）の空間構造は測定の零空間にあり、原理的に回復不能。
これを v7 では y-Fourier モード分解（k_y=0 のみ可測）で定量表示する。

### 「傾けたとき実際どこから見ていることになるか」への答え

回転後に SG で読む F_z' の期待値は演算子恒等式（全次数で厳密・近似なし）:

```
R_y(β)† F_z R_y(β) = cosβ·F_z − sinβ·F_x   （ŷ 傾け → ⟨F_x⟩ が混ざる）
R_x(β)† F_z R_x(β) = cosβ·F_z + sinβ·F_y   （x̂ 傾け → ⟨F_y⟩ が混ざる）
```

つまり「傾けてから z を測る」=「傾ける前のスピンを方向 n(β) 沿いに測る」。
カメラの幾何学的視点は動かない。動くのはスピン空間の測定軸だけである。
（符号は過去に実バグを踏んだ点: ŷ 回転は −sinβ、x̂ 回転は +sinβ。audit_v7 が毎回検証。）

## 測定プロトコル

| 名前 | 軸 | 角度 | 用途 |
|---|---|---|---|
| id | — | 0° | protocol（⟨F_z⟩） |
| y±16 | ŷ | ±16° | protocol（⟨F_x⟩ = −(s₊−s₋)/2sin16°） |
| x±16 | x̂ | ±16° | protocol（⟨F_y⟩ = +(s₊−s₋)/2sin16°） |
| y−90 / x+90 | ŷ/x̂ | −90°/+90° | exact90 参照（誤差内訳の分離用） |
| y+30 / x−30 | ŷ/x̂ | +30°/−30° | held-out（再構成に不使用＝循環論法の遮断） |

可視ブロック m ∈ {−6,−5,−4,−3} が実験チャネル（16° で可視率 ≈90%）。
全13チャネル像は `sim_only/` として保存し、切り詰めバイアスの定量にのみ使う。

### 角度セットは設定変更可能（ユーザー要件 2026-07-02）

デフォルトは上表（x,y 各 ±16°）だが、プロトコルは環境変数で自由に差し替えられる:

```
V7_TILT_SPEC="id,y+16,y-16,x+16,x-16"          # デフォルト
V7_TILT_SPEC="id,y+13.8,y-13.8,x+13.8,x-13.8"  # 例: 13.8°
V7_TILT_SPEC="id,y+16,y-16,y+32,y-32,x+16,x-16" # 例: 多角度スキャン
V7_HELDOUT_SPEC="y+30,x-30"                     # held-out も同形式
```

再構成はハードコード差分式ではなく、**任意設定対応のピクセル毎最小二乗**
`s_k = n(â_k, β_k)·⟨F⟩`（n = Rodrigues 一般式、≥3 独立方向で可解）。
`sg_raw_v7.h5` は settings テーブルを内蔵する自己記述型で、`recon_from_pixels.py`
は raw ファイルの記述だけを読む — 将来の実データ（任意の角度リスト）にそのまま適用可能。
audit がデフォルト設定時に「pinv 解 ≡ ±16°閉形式」の一致を機械精度で検証する（3c）。

## パイプライン（ファイアウォール構造）

```
psi13 (truth) ──> sg_forward.py ──> sg_raw_v7.h5   （生ピクセルデータ＝観測量）
     │                                   │
     └──> truth_reference.py             └──> recon_from_pixels.py （ψを一切見ない）
              │                                   │
              └────────> audit_v7.py / viz_v7.py <┘   （ここで初めて比較）
```

1. `sg_forward.py` — 全フレームの大域スピントレース→代表≈5フレーム自動選定
   （初期/立上り/過渡傾き最大/緩和/末期; `FRAMES=` で上書き可）→ 9設定×per-m
   カラム積分像を書き出し。
2. `truth_reference.py` — 真値場（3D・カラム積分）を独立計算。
3. `recon_from_pixels.py` — ピクセルデータのみから: 5設定カラム⟨F⟩再構成
   （vis/all13）＋ 90°参照 ＋ 3D推定2種:
   - **uniform**: 最小 ‖∇f‖ 解。ノイズなし極限で任意の平行移動不変な滑らか事前分布は
     「y 一様スプレッド」に厳密退化する（λ 非依存; 導出はスクリプト docstring）。
     これは真値の k_y=0 射影に等しく、**無事前分布の理論下限**を達成する。
   - **ansatz**: 等方トラップの x↔y 対称性を使い、測定カラム密度の x-プロファイル
     形状を y-プロファイルとして流用する形状事前分布（実験で入手可能な情報のみ）。
4. `audit_v7.py` — 7系統の敵対的検証（演算子代数・回転恒等式・解析コヒーレント状態での
   エンドツーエンド機械精度・データ内ユニタリ性・Fz整合・held-out・大域⟨Fz⟩保存と
   可視ブロック欠損の分離）。1つでも FAIL なら exit≠0。
5. `viz_v7.py` — Fable finalize 版の定量可視化。スピン方向は正典と同じ**HSV方向
   エンコード**（hue=方位角φ_F, value=Fz符号, sat=面内成分, alpha=密度エンベロープ）を
   背景に、面内成分を**物理長の矢印**（規格化しない・微小は点）で重ねる。出力:
   - `v7_geometry.png` 幾何模式図（視線=ŷ, SG=ẑ, スピン空間回転）
   - `v7_raw_montage_f####.png` 生データ（設定×可視チャネル、原子数分率つき）
   - `v7_column_texture_f####.png` **測定面(x,z)**: truth vs recon のスピンテクスチャ＋
     ⟨Fy⟩＋偏極＋色相環＋相関表（重なりなし）
   - `v7_crosssection_f####.png` **断面(z-slice, x-y面)**: truth の3Dスピン渦（hue周回）と
     recon ansatzを並べ、視線(y)方向で失われる構造を可視化
   - `v7_3d_recon_f####.png` 3D推定 vs truth スライス＋y-モード予算（下部に整形表）
   - `v7_epochs_summary.png` 時間発展サマリ（HSVテクスチャ）＋metrics CSV/JSON

## 既知の注意（引き継ぎ）

- `extract_psi13.jl` の `t` はゼロ埋めバグ → 時刻は必ず goto.h5 から（`frame_times_ms` が検証込みで担当）。
- psi13 の h5py 生 shape は (nv,nv,nv,nf)（フレーム軸は**最後**）。`submit_viz_v6.sh` の
  `shape[0]-1` は 96 を返す潜在バグで、v7 では `shape[-1]` を使う。
- per-atom カラムテクスチャは |s|≤6 に数学的に有界 → マスク・フロア不要で全格子表示が成立。
- ⟨F_z⟩ 保存則の確認は必ず全13チャネルで行い、可視ブロック欠損（漏れ原子が担うスピン）と分離する。
