## Schema / dispatcher fixes during this pivot (2026-05-26)

While preparing the Eu robust factorial, two latent issues were found
in the dynamics-step LHY plumbing:

1. **Schema rejected `dynamics.lhy:`**. `DYNAMICS_SCHEMA` (in
   `src/workflow/experiments/schema/schema.jl`) did not declare an
   `lhy` key, so any explicit LHY override in a dynamics step was
   silently rejected with an `Unknown key` error.
2. **Dispatcher dropped non-scalar LHY**. `_run_step(::DynamicsStep)`
   (in `src/workflow/experiments/pipeline/run_step_dynamics.jl`)
   constructed its workspace **without passing `spinor_lhy=`** to
   `make_workspace`. For scalar LHY this was masked by the
   `interactions.c_lhy > 0` fallback in `make_workspace` (a non-zero
   `c_lhy` inherited from the preceding GS step's `prev_interactions`
   triggers `ScalarLHY` construction), so the scalar-LHY case
   accidentally worked. For non-scalar LHY (`polar_two_channel`,
   `full_bdg`, `polar_contact`, `polar_dipolar`, `fm_contact`,
   `fm_dipolar`, `icosahedral`) the only entry point is the
   `spinor_lhy::Symbol` kwarg, which was never passed — so any
   dynamics step inheriting a non-scalar LHY GS had **zero LHY
   contribution during dynamics**.

Both issues fixed in this commit cycle. Historical impact audited:
`grep -r "kind: (polar_two_channel|full_bdg|polar_contact|polar_dipolar|fm_contact|fm_dipolar|icosahedral)"`
across `runs/` (excluding `_loop/`) returns **zero matches** —
every historical production run used scalar LHY, where the
accidental `c_lhy`-fallback path was correct. The fix is therefore
forward-looking; no L4 / Matsui retroactive re-runs are required.

The fix unblocks the `lhy:` axis of the Eu robust factorial
(`runs/eu_robust_factorial/K?_gdr?_LHY?.yaml`) for explicit and
auditable control.

## Known limitations (do not "fix")

These are intentional design boundaries documented in CLAUDE.md.
They affect interpretation, not correctness.

1. **PolarTwoChannelLHY at F=6** off by 30–70% (`memory:full_bdg_F6_polar_broken`).
   Use `PolarContactLHY` / `IcosahedralLHY` for F=6 polar; FullBdGLHY at
   F=6 polar emits `@warn` (~3000× spurious offset).
2. **Spinor LHY for F ≥ 3 is research-open**: no closed-form
   Lima-Pelster generalisation exists. The scalar approximation +
   `@warn` is the honest signal.
3. **Secular DDI is user-chosen**, with an `@info` advisory when
   `ω_L / (c_dd ⟨n⟩) > 100`. Production Eu runs almost always live
   in that regime; choice is documented per-YAML.
4. **spin_rotating_frame_omega ≠ 0 requires secular_ddi=true** (enforced
   via `ArgumentError`). Off-diagonal DDI only Larmor-averages to zero
   in the secular limit.
5. **Bz `{from, to, duration: 0.0}` is not an instantaneous quench**
   (`memory:gotcha_bz_ramp_duration_ignored`). Inner `duration` is
   ignored by `_make_waveform`; outer step duration becomes the ramp
   time. The L4 Eu Ham-only configs all have this latent issue
   documented but not fixed.

## Production claim shape

Under the validation evidence above, production Eu runs may claim:

> Conclusions are robust across [DDI on/off] × [loss on/off] × [K3
> on/off] × [γ_dr on/off] × [scalar LHY on/off] × grids {64, 96, 128}
> × dt {0.005, 0.0025} × seed ensemble {N}, with operators verified at
> machine precision against an independent reference RHS and grid
> convergence pinned at ΔF_z = 0.00886.

This is the *post-pivot* claim shape. The older "matches Ueda" shape
is paused.

### Five publishable findings (consolidated 2026-05-26, post-2×4-factorial)

1. **L4 isotropic Eu EdH is robustly no-collapse across 64/96/128.**
   The pre-dealias "64³+ collapse" intuition was a numerical artifact.
2. **Matsui-style loss-free simulation (N=50k, c1/c0=+1/36,
   near-spherical, m=−F init) qualitatively reproduces Fig 2C:**
   m=−6 → m=−5 → m=−4 EdH cascade with N conserved and partial
   coherent recovery at long time. 32³ ↔ 64³ grid converged for
   spin-sector dynamics.
3. **scalar LHY at F=6 is insufficient.** scalar n^{5/2} LHY is
   indistinguishable from no LHY in the F=6 cigar collapse regime
   (4 cells confirm: K3=0 LHY=off ≡ K3=0 LHY=scalar; K3=200 LHY=off ≈
   K3=200 LHY=scalar).
4. **A spinor-branch-aware effective LHY closure
   (polar_contact / icosahedral) alone stabilizes the F=6 collapse
   stress regime, K3 not required.** At K3=0, both polar_contact and
   icosahedral LHY produce stable_arrest with N(T)/N(0) = 1.000
   (lossless in the 30 ms simulated window). The arrest mechanism is
   the LHY closure, NOT K3. Note this is still an effective closure
   tied to an assumed local order parameter — NOT a full
   nonequilibrium F=6 BdG-LHY calculation.
5. **K3 is not the primary arrest mechanism in F=6 collapse-prone
   regimes.** Adding K3=200×proxy on top of proper LHY reduces peak
   ratio marginally (1.63→1.40) at the cost of 17.5% atom loss.
   K3 is not required for arrest in this benchmark; it mainly adds
   atom loss. (K3 may still play a role in real experiments via the
   actual physical 3-body collision rate, which is a separate question.)

### Methodological claim (publishable as a warning):

> **F=6 high-spin dipolar collapse predictions are strongly
> model-dependent at the LHY level.** With scalar LHY: appears to
> need K3 = 200× proxy for sacrificial arrest. With proper spinor LHY:
> K3 not needed, arrest is lossless. The question "does K3 arrest
> collapse?" is ill-posed without first specifying the LHY closure.

### Caveats on the "proper spinor LHY" claim:

- polar_contact / icosahedral LHY are **effective model closures**
  tied to assumed local order parameters (polar phase / I_h F=6
  symmetric state respectively). They are NOT a full nonequilibrium
  F=6 BdG-LHY treatment.
- "Stable" applies only to the simulated time window (t ≤ 20 dimless
  ≈ 30 ms). Long-time metastability is being tested via the 50/100/
  200 ms LHY stability ladder (Task #26).
- This methodological warning does NOT change the L4 isotropic main
  result; the experimental protocol does not enter a collapse-prone
  regime, so LHY model choice is moot there.

> **2026-07-29 — the four `LHY1` cells did not have LHY on during dynamics.**
> `_resolve_lhy_block!` ran only for the ground_state step (#174), so a
> `dynamics: {lhy: {kind: scalar}}` block reached `make_workspace` unresolved
> and `interactions.c_lhy` stayed 0. The GS-phase LHY was applied; the dynamics
> phase was not. So `LHY0` vs `LHY1` here compares *ground states*, not
> trajectories, and the ⟨F_z⟩/N spread of 0.05% between them is the residual of

>

> K3 and gdr as well, and those knobs were live. What cannot be claimed from
> this table is robustness *to LHY* during the dynamics. Being re-measured.

**Robust conclusions (invariant across all 8 cells):**

- **EdH transfer signature**: ⟨F_z⟩/N falls from −F=−6 (initial m=−F)
  to ≈ −2.69 at t = 6.28 dimless (10 ms). Variation across the 8
  factorial cells: < 0.15% (max 2.6926, min 2.6881). Well inside the
  ±30% tolerance band. Sign invariant.
- **LHY peak-density suppression**: LHY ON shifts peak density from
  5.13e−3 to 5.11e−3 (≈ 0.5% reduction) consistently across all
  (K3, γ_dr) combinations. The repulsive n^{5/2} correction shows
  up cleanly and additively.
- **Norm conservation under Hamiltonian-only**: LHY-on, loss-off cell
  norm = 1.0000 exactly. LHY adds no non-conservative dynamics.

**Non-robust observations (axis-dependent):**

- **N(T)/N(0)**: mass conservation depends on which dissipative axis is
  on. K3 alone (1e−41 m⁶/s) gives 0.27% loss over 10 ms; γ_dr alone
  (0.02 dimless) gives 0.015% — K3 is ~20× stronger at these literature-
  proxy values. Combined K3+γ_dr is approximately additive (0.29%).
  Any quantitative claim about N(t) must enumerate which loss channels
  are on.

**Not yet observed at this t/grid:**

- **K3 peak-density clamp**: not visible at t = 6.28 dimless / 32³. K3
  reduces peak by < 0.05%. To see the canonical "K3 clamps collapse
  peak density" effect, run longer (t → 10×) or at higher resolution
  where Hamiltonian-only collapse is detectable.
- **Texture-class flip**: `phase_classify` analyzer ran per cell but
  the comparison across cells is left for the larger N=64/96 sweep
  (next session).

**Bottom line**: at 32³ / 10 ms / literature-proxy loss coefficients,
the qualitative EdH conclusion is robust. The dissipative axes show
small additive corrections in directions consistent with their physics.
LHY contributes a small repulsive shift. No axis flips the answer.

### Extension — L4 K3 collapse-arrest ladder, 64³ subset (2026-05-26)

Source: `runs/l4_k3_ladder/L4_K3_n64_*/`. Same Eu Matsui baseline as
above, but grid 32³ → 64³ and `t_evolution = 20.0` dimless (≈ 32 ms,
3.2 × τ_EdH). Goal: push into the "Hamiltonian-only collapse-dominated"
regime where K3 can be tested as a density arrest mechanism.

```
cell         peak_max     N(T)/N(0)   Fz/N(T)    coll_onset  loss_onset
HamOnly      9.511e-03    1.0000      -1.7023    (none)      (none)
K3           9.498e-03    0.9914      -1.6902    (none)      t=2.50
gdr          9.511e-03    0.9993      -1.7024    (none)      (none)*
K3+gdr       9.498e-03    0.9907      -1.6903    (none)      t=2.50
K3+LHY       9.538e-03    0.9913      -1.6956    (none)      t=2.50
```
\* γ_dr alone gives 0.07% loss but doesn't cross the 0.999 onset threshold.

**Physics findings (load-bearing for the K3 hypothesis):**

1. **No runaway collapse observed.** At t = 20 dimless / 64³ /
   L4-Matsui baseline (N = 30000, isotropic ω = 1), peak_density only
   reaches 1.85 × the 32³ short-time value — nowhere near the runaway
   `peak → ∞` signature collapse would produce. `collapse_onset` (peak
   > 2 × initial) never fires.
2. **K3 mass loss scales linearly with t.** 32³ at t=6.28 gave 0.27%
   loss; 64³ at t=20 gives 0.86% — ratio 3.19, matches t-ratio 3.18.
   K3 plumbing is consistent across grids.
3. **K3 is not arresting anything yet.** peak_max with K3 (9.498e-3)
   is essentially identical to HamOnly (9.511e-3). K3 is contributing
   pure mass loss, not density clamp, because there is no density
   instability to clamp at these parameters.
4. **γ_dr is 12× weaker than K3 here.** γ_dr=0.02 gives 0.07% loss vs
   K3=1e−41 m⁶/s giving 0.86% at the same N, t. Reasonable order

### Time-window caveat (anko, 2026-05-26): "stable" applies only to the simulated window

The "stable_arrest with N=1.000" claim is currently demonstrated at
`t_evolution = 20 dimless ≈ 29 ms`. This is **not** equivalent to
"stable forever". Four possible reasons the apparent arrest could
break down at longer time:

1. **Metastable plateau.** A weak instability mode (Γ⁻¹ ≫ 30 ms)
   could grow over 100 ms – 1 s and trigger delayed collapse, even
   though the 30 ms window looks flat.
2. **LHY closure drift.** polar_contact / icosahedral LHY assume a
   specific local order parameter. As the dynamics spreads spin
   populations across m-components, the effective LHY closure may
   stop matching the actual non-equilibrium BdG fluctuation pressure.
3. **Numerical heating at long t.** 1 s ≈ 691 ω_ref⁻¹ ≈ 6.9 × 10⁶
   Strang steps at dt=1e-4. Cumulative dt-error, FFT roundoff, and
   energy drift over that many steps are non-trivial.
4. **Experimental side-channels.** Real experiments have background
   loss, three-body loss, spin-dependent loss, magnetic noise,
   technical heating — none of which the Hamiltonian + LHY simulation
   captures. Stability in the simulation window does not predict
   experimental stability per se.

The honest current claim is therefore:

> **In the simulated time window (`t ≤ 20 dimless ≈ 30 ms`), polar /
> icosahedral LHY at K3=0 give lossless stable_arrest at the cigar
> regime. Long-time metastability beyond this window is untested.**

NOT:

> ~~polar / icosahedral LHY arrest the collapse permanently.~~

A long-time stability ladder (`runs/eu_lhy_longtime/`, Task #26)
extends the test to 50 ms / 100 ms / 200 ms with the same proper LHY
model, K3=0, monitoring peak density, energy drift, and texture
stability. If those clear, the next test is BdG linear stability
around the arrest state. If a delayed collapse is observed, the
question becomes "metastable vs numerical heating" via dt/2 + grid
upscaling + seed × 3 controls.
