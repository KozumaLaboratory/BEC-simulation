# What one day of chasing "the docs disagree with the code" found

> **FROZEN 2026-08-04.** A dated record of that day. Not maintained against the
> code — the numbers below were true when measured and are cited with their
> conditions so a later reader can tell.

The starting request was about references: *"a feature that was deleted stays
half-written in the prose, someone puts it in a config, and it breaks."* That is
one symptom. Chasing it turned up **twelve defects in the code**, because a
document disagreeing with the code is a coin, and nobody had been looking at the
other face.

---

## 1. The scale, measured

| | |
|---|---|
| docs files read (every one, adversarially verified) | 183 |
| rows carrying claims about the code that are **no longer true** | **98 of 184** |
| anchors CLAUDE.md sends every reader to, that are stale | **7 of 10** |
| distinct facts stated in more than one place | **105** |
| total copies of those facts | **593** (mean 5.6 each) |
| duplicate sets whose copies **already disagree** | **84 (80 %)** |

The last line is the whole diagnosis. **The 98 stale rows are not 98 people
writing 98 wrong things.** They are one fact restated five times, each copy
drifting alone.

## 3. Why no test caught any of this

Five gates, one shape. **Each built its input out of the vocabulary of the thing
it was testing:**

```julia
@test is_divergent_status(Dict("norm_drift" => 0.5))   # the reader's own key
@test classify_failure(Dict(), "OUT_OF_MEMORY|...")    # the matcher's own literal
write(rd/"outcome.toml", …); analyze_failure(e)        # the artefact, self-produced
@test linear_zeeman_p(Eu151, …) > 0.3                  # written to match the bug
# and a canary perturbing c1 on a POLAR state, where ⟨F⟩ = 0 makes it inert
```

> **A gate that constructs its input from the thing under test never crosses
> the producer/consumer boundary, and that boundary is the only place this
> class of defect lives.**

The TWA gate then failed the same way *while being written*: it tested the
predicate, the weighting and the record, and **stayed green when the rejection
branch was disabled outright**. Every piece covered; nothing checked that the
loop consults them.

## 4. What was done about it

**Consistency by subtraction, not repair.**

```
LIVE    24 files — must be true, and are gated
DATED  158 files — carry the date they describe, and say they are not maintained
```

A dated document **does not need to be true**. It becomes harmless the moment a
reader can see it is a record rather than a description — which is exactly what
the Zeeman sign bug lacked: three files taught an inverted lab-field sign with
nothing to say when they had last been checked. Consistency cost now scales with
|LIVE|, not with the file count.

`AGENTS.md` went from 138 lines to a 28-line pointer: it was involved in **28 of
the 84 disagreements**, and reachable from exactly one line anywhere — CLAUDE.md's
own note saying not to trust it.

**Twelve gates**, all canaried, several in both directions:

| gate | holds |
|---|---|
| `test_docs_live_set.jl` | the LIVE/dated split is honest; a NEW doc is red until classified |
| `test_docs_yaml_against_schema.jl` | a maintained doc may only teach keys the schema accepts; the reference's top-level table must **equal** `TOP_LEVEL_KEYS` |
| `test_schema_enum_matches_implementation.jl` | schema enums equal what the implementation dispatches on, **both directions** |
| `test_design_docs_have_no_latex.jl` | the design docs stay terminal-readable |
| `test_live_status_reaches_the_detector.jl` | the real callback writes a file, the real predicate judges it — nothing synthetic between |
| `test_terminal_record_has_a_producer.jl` | no code may name a file nothing writes |
| `test_budget_reads_the_save_block.jl` | the budget honours the real cadence, with a control that cadence *moves* the count |
| `test_twa_rejects_diverged_members.jl` | a diverged member is refused — and the LOOP consults the guard |
| `test_code_rev_refuses_under_sysimage.jl` | no revision is recorded that cannot be vouched for — and an ordinary process still records |
| `test_prose_does_not_move_identity.jl` | prose cannot move `artifact_id`; seven physics axes must |
| `test_verdict_truth.jl` | a marker's verdict is re-derived at the payload it describes |
| `test_gs_step_returns_one_state.jl` | saved ψ, workspace and energy are one object |

**The design's own open list** went from 14 unresolved ids to **2**. The two
that remain need a TSUBAME job (real money) or an observation of usage — neither
is closable by argument, so neither is closed.

## 5. Retractions

Three claims were withdrawn during the day, two of them mine from the same day:

1. **The whole parity investigation.** `parity_before` was main's *tip* and
   `parity_after` a branch cut 213 commits earlier, so "before vs after the
   cutover" compared **two divergent trees**. The bisect could not have found
   anything else: `git rev-list origin/main..branch` excludes main's side *by
   definition*, so the true parent was unreachable and the first probe unwound
   213 commits while applying one.
2. **"Alignment noise."** I named a mechanism for cross-process ψ variation and
   then measured it: a 64³ in-place complex FFT is **bit-identical** from a
   64-byte-aligned and a 16-mod-64 buffer, under both ESTIMATE and MEASURE. The
   cause remains unidentified and is bounded at 1e-16.
3. **"`@nospecialize` is the load-bearing annotation."** I wrote that into
   CLAUDE.md in the morning, correcting an unverified claim by adopting another
   unverified claim. Measured that evening: **13.9 s / 14.1 s / 14.2 s / 14.5 s
   against a 0.6 s spread.** Neither annotation is load-bearing. What defused
   the original hang was keeping an `Any`-typed local out of `make_workspace`.

## 6. Lessons

Ordered by how much they cost.

### 6.1 The cost of consistency scales with the number of independent restatements

Not with the number of documents. Five copies of a fact are five things that
drift; the fix is subtraction, not diligence. **Prefer a pointer to a
restatement, and a derivation to a transcription** — the coverage scoreboard
said "5 / 16 terms" for two months where the answer is 14/14, and now shows the
two expressions that compute it instead of a number someone typed.

### 6.2 A dated document does not need to be true

This is the cheapest consistency mechanism available and it was missing
everywhere. **But a date is not a licence for a withdrawn number**: a retracted
`~3000×` figure inside a dated file was still being read as a reason to avoid a
working code path.

### 6.3 Absence must never fold into health

Every instrument failure of the day was this shape, and so were several of the
defects:

- `--include=*.jl` unexpanded by zsh → **"0 matches"** read as *absent*
- a YAML parse failure caught into an empty array → **`findings=0`** printed
- a regex anchored to line start matching nothing → **two empty sets compared
  equal** and reported as agreement
- `is_divergent_status` defaulting a missing key to `0.0` → **a diverging run
  reads as healthy**

**Every scan needs a calibration**: a known-live input must be seen, and a
planted defect must be caught. `duration:` matching 336 times is what made
"5 dead YAML keys" trustworthy after a first pass reported 388.

### 6.4 A gate must cross the boundary

State the producer/consumer boundary and test across it with real artefacts:
the real writer writes, the file is read back off disk, the real reader judges.
**Canary both sides** — delete the key from the writer, rename it in the reader.
Testing the pieces is not testing the seam.

### 6.5 Before an A/B across commits, print `git merge-base` and both leg counts

Two numbers, free, and they would have saved a GPU day. `A..B` excludes A's side
by definition; if the walk's first element already differs, suspect the range
expression before believing the result.

### 6.6 Read before spending

Read → local 8³/16³ → CI → TSUBAME (real money). Reading the diff took thirty
seconds and made two of four cluster jobs unnecessary. **Ask "does anything
depend on this?" before "what is the mechanism?"** — the config whose 8.5e-6
discrepancy consumed a day reports `conv=false` at all 20 points and is cited by
zero tests and zero figures.

### 6.7 A number without its conditions is not reusable, and a cause without a control is not isolated

The measurement ledger's most useful rows are the negative ones. "Alignment was
hypothesised and refuted" prevents the next person from proposing it. A row
asserting a cause while excluding nothing was downgraded to *unsettled*, not
kept as established.

### 6.8 A retraction that lives only in the index is a retraction nobody sees

`ΔFz/N = 4.6` was withdrawn on 2026-07-05 because the `Lz` column was **all NaN,
0 of 604 rows** — the quantity the mechanism is defined by was never measured.
Only the index carried that. The page itself still read as *"the
highest-leverage target right now."*

### 6.9 Do not correct an unverified claim by adopting another one

Both halves of the `@noinline` / `@nospecialize` dispute were assertions. The
right move was to measure, and it took twenty minutes.

### 6.10 An enum wider than its implementation is worse than one that is narrower

Too narrow throws at load, in front of the user. Too wide accepts, runs, and
omits the physics.
