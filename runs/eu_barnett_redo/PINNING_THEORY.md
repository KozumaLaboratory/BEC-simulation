# −Ω が −6 に張り付き、Ω=0 は張り付かず、+Ω は広がる ── 理論の確認

投入前に「その描像が理論的に正しいか」を確かめた記録。2026-09-08。

## 1. 保存則（これは確立している）

B ∥ z（B = 0 を含む）ではハミルトニアンがスピンと空間の**同時 z 回転**で不変なので、
Noether により

    J_z = L_z + F_z   が厳密に保存する。

数値でも立っている: 全 5 腕で `leak = 0.0000`、`J_z` は 4〜5 桁一定。
**これは仮定ではなく、コードが満たしていることを確認した恒等式。**

## 2. 束縛（これも疑いようがない）

    F_z = Σ_m m |c_m|²,   m ∈ [−6, +6]   ⇒   F_z ∈ [−6, +6]

そして **`F_z = −6` は m = −6 に全population がある状態に限られる**ので、
そのとき必然的に `|⟨F⟩| = 6`（完全偏極）かつ**スピン組織（texture）はゼロ**。

## 3. 緩和先が何を望むか（観測から）

B = 0 では m が縮退するのでスピンの向きは自由。そこで働くのは

| 項 | 値 | 何を望むか |
|---|---|---|
| DDI | `c_dd = 120.7`, `ε_dd = 0.54` | **異方的。スピン組織と軌道循環を望む** = Einstein–de Haas |
| c₁ | **−13.4 < 0**（強磁性） | 脱分極に抵抗する（`|⟨F⟩| = 6` を望む） |
| 運動エネルギー | ─ | 軌道角運動量に対価を要求する（渦・剛体回転） |

観測（B=0, J_z = −6）: `F_z: −6.00 → −2.17`、`|F|: 6.0 → 1.8`、`L_z: 0 → −3.83`。

⇒ **DDI が勝つ。** 初期の完全偏極状態は緩和先ではなく、状態は脱分極して
J_z の 64 % を軌道へ移す。これが Ω=0 でも +3.83 動く理由。

## 4. 張り付きの論証

J_z をさらに負にする。`F_z ≥ −6` がスピンの取り分に蓋をするので

    L_z = J_z − F_z  ≥  J_z + 6

を軌道が必ず負担する。軌道角運動量は運動エネルギーの対価を要求し、その対価は
`|L_z|` とともに増える。だから系は**もっとスピンに入れたい**が、入れられない。

⇒ **`F_z` は −6 に飽和する。**

そのとき全 population が m = −6 にあり `|⟨F⟩| = 6`、**スピン組織は完全に抑圧される** ──
DDI の望みが束縛によって完全に阻まれた状態。

### ★これは「急に切り替わる」のではなく「なだらかに飽和する」

一様 m = −6 状態でも DDI はそこにあり、依然として組織を作りたい。作れば `F_z` が
−6 から離れ、`J_z` 保存により `L_z` が動き、運動エネルギーを払う。
`|J_z|` が大きいほどその対価が DDI の利得を上回る。

**つまり張り付きはエネルギー的な釣り合いであって、絶対禁止ではない。**

⇒ **予言される観測量は「`F_z`(終) 対 `J_z` の曲線が折れて −6 に漸近すること」。**
鋭い閾値ではない。だから **1 点ではなく走査**でなければ見えない。

## 5. +Ω が「全体に広がる」

J_z を正に大きくすると `F_z` は正を望む。初期状態は m = −6 なので、そこへ行くには
**population が梯子 m = −6 → +6 を渡る**。途中は全 m に分布する。
終端は `F_z > 0` かつ `|⟨F⟩|` が小さい（部分偏極）。

⇒ **張り付きの正反対**。同じプロトコル・同じ初期状態で、回転の符号だけで
「1 つの m に凍結」と「全 m に拡散」が出るなら、それが最も強い描像。

## 7. この描像を壊しうるもの（全部書く）

1. **注入の飽和。** 加速が続く保証はない。雲が回転で膨らめば結合が落ちる。
   ⇒ **緩和策: 長さを 3 点走査する。** 外挿でなく測る。
2. **渦が軌道の対価を下げる。** `pk_s30` の腕は長いかき混ぜで渦 22〜57 本を作っていた。
   渦格子は剛体回転より安く `L_z` を運ぶので、**軌道の対価が下がり張り付きが遅れる**。
   ⇒ 閾値が 46 より大きい方へずれる可能性。**符号は分かるが大きさは分からない。**
3. **分配則が 3 点の当てはめ。** `J_z ∈ [−11.4, −0.5]` で測ったものを −31 まで
   外挿している。**折れ曲がりが物理で、閾値の数値は信用しない。**
4. **箱の汚染。** いま `edge_frac` は 1e-9〜1e-21（`L_z ≈ 5.5`）。`L_z ≈ 25` では
   雲が広がるので大きくなる。**box28 は 68 % 漏れで汚染扱いになった前例がある。**
   ⇒ 走行中に `edge_frac` を見る。1e-6 を超えたらその腕は棄却。
5. **分配則は B=0 で測った。** 今回は B_final = 30 µG（`ω_L/μ = 0.06`）。小さいが
   ゼロではない。しかも 30 µG は `F_z = −6` を**エネルギー的に有利にする**向き
   （m = −6 が Zeeman 基底状態）なので、**張り付きを助ける**方向。
