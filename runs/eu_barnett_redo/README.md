# Rotation-driven magnetisation in a ¹⁵¹Eu F=6 dipolar BEC — decisive core

Clean redo of `runs/eu_barnett_rotfield_clean/` (PR #62) on corrected code.
This directory holds the **decisive core only**: the three measurements that can
falsify the claim. Parameter surveys are deliberately absent — the previous
round produced ~40 figures exploring Ω, amplitude, cone angle, box, dx and dt,
and none of them tested the claim.

## The claim

A magnetic field rotating about **z** stirs the cloud through the dipolar
coupling, nucleating vortices (orbital angular momentum `L_z`). Quenching the
field to zero unpins the spin, after which the DDI — the only remaining
spin–orbit coupling — converts orbital angular momentum into **axial
magnetisation** `⟨F_z⟩`. This is the reverse of Einstein-de Haas: the Barnett
effect. The sign of the induced magnetisation is set by the sense of rotation.

## What actually carries the claim

**The `J_z` ledger, and nothing else.**

At `B = 0` the Hamiltonian (kinetic + axially symmetric trap + c₀ + c₁ + scalar
LHY + DDI) is invariant under a *simultaneous* rotation of spin and space about
z. Noether then makes

```
J_z = L_z + ⟨F_z⟩
```

exactly conserved, while `L_z` and `F_z` are individually free to move. So the
statement "orbital angular momentum became magnetisation" is precisely the
statement "`L_z` fell, `F_z` rose by the same amount, `J_z` stayed flat". If the
ledger leaks, no number downstream of it means anything.

The previous round measured a ~40% `J_z` drift over the quench and closed it as
"time discretisation, converges as dt→0". That was wrong: the drift is a
**box** artefact and is flat in both dt and propagator order
(`test/oracles/test_jz_conservation_ddi.jl`). Boxes here are therefore sized by
**edge density**, and `edge_frac` is reported with every point.

## Protocol

Three stages, all on the standard `kind: spinor` path so every observable is
already in the lab frame.

1. **Ground state** — trap `ω = (1, 1, 2)`, field along `+x̂`. Since
   `p ≡ −g_F μ_B B < 0` for `g_F > 0`, the spin relaxes **anti-parallel** to the
   field: `⟨F⟩ = (−6, 0, 0)`. `F_z = 0` by construction, which is what lets the
   sign of the Barnett signal flip cleanly (a z-polarised start puts the effect
   on a large pedestal and the sign never reverses).
2. **Stir** — field of constant magnitude rotating in the xy-plane at rate Ω.
3. **Quench** — `B → 0`. Larmor precession stops; `F_z` becomes static and the
   conversion is read off directly.

### The ± arms are exact mirror images

The setup is symmetric under reflection in the xz-plane: `B_y → −B_y`,
`Ω → −Ω`, `F_z → −F_z`, `L_z → −L_z`, with the GS spin along `−x̂` invariant.
The two arms are therefore generated by **negating `B_y`**:

```
Bx = A·sin(Ωt − π/2)          # both arms, identical
By = A·sin(Ωt + φ_y),  φ_y = π  → CCW (+Ω)
                       φ_y = 0  → CW  (−Ω)
```

`SinusoidalWaveform` is **sin**, so `φ_x = −π/2` puts `B(0) = −x̂` — aligned
with the GS spin — in *both* arms. No nutation kick, and the only difference
between them is the rotation sense.

The previous round used `φ_x = ±π/2, φ_y = 0`, which under the `sin` convention
gives `B(0) = ±x̂`: the `+Ω` arm started 180° **anti-aligned** with the spin
while `−Ω` started aligned. The rotation senses were right, but the arms
differed by an initial condition as well, so the reported magnitude asymmetry
("chirality-selective depolarisation") has an untested alternative explanation.
See `mistake_barnett_chirality_arms_not_mirror_images_2026_07_28` in memory.

### Ω = 0 is a field-on control

With `B(0) = −x̂` aligned with the spin, `Ω = 0` leaves a *static* field that
exerts no torque. Nothing should happen. This is stronger than switching the
field off, because it separates "rotation is required" from "a field is
required".

## Running

```bash
# smoke (every code path, small, ~2 min)
SMOKE=1 julia --project=. runs/eu_barnett_redo/run_core.jl

# one production cell
BR_CELL=plus julia --project=. runs/eu_barnett_redo/run_core.jl

# TSUBAME: one job per cell
qsub -g tga-kozuma-kouhi runs/eu_barnett_redo/tsubame_core.sh
```

Grid note: FFT sizes are chosen with small prime factors. The previous round
found `n=112` to be ~66× slower per step than `n=80` and abandoned fine grids as
infeasible — `112 = 2⁴·7`, and that factor-7 transform is a large part of it.
`96 = 2⁵·3` sits between the two in size and is FFT-friendly.

## Results

### The claim

**Of the orbital angular momentum lost after the quench, ~99% becomes spin.**

| quantity | value | why it is trustworthy |
|---|---|---|
| conversion efficiency `ΔF_z/|ΔL_z|` | **0.991** | identical at box 42 and 46.7 (0.9916 / 0.9912) and flat across the whole quench |
| `J_z` ledger leak | **0.9%** of the signal | edge fraction 2.4e-10, four orders under target |
| rotation is the cause | `Ω=0` gives `J_z ≡ 0` | leak 7.5e-07 — a static field exerts no torque |
| the DDI is the mechanism | DDI off gives `L_z ≡ 0` | leak 2.1e-12; without it the rotating field nucleates nothing |
| the sign follows the rotation | `±Ω` mirror to four digits | every column, including the leak |

### Why the efficiency and not ΔF_z

`ΔF_z` is a **transient**. It rises through the entire quench (0.27 → 1.06 over
t = 40 → 80, still rising at the end) and it rises with the box:

| box | ΔF_z | ΔL_z | efficiency | leak/conv | edge_xy |
|---|---|---|---|---|---|
| 35 | 0.9240 | −0.9422 | 0.9806 | 2.0% | 1.95e-05 |
| 42 | 1.0133 | −1.0218 | 0.9916 | 0.8% | 8.90e-07 |
| 46.7 | 1.0609 | −1.0704 | 0.9912 | 0.9% | 2.41e-10 |

Same cause for both: once the field is off the cloud expands freely, so a wider
box or a longer window each let the relaxation run further. Quoting `ΔF_z` means
quoting the window. The **ratio** removes the window — a 15% spread collapses to
1.1%, and to 0.04% between the two boxes that meet the edge target.

The stir output is converged (`J_z` at quench start: 8.6904 / 8.7026 / 8.7052,
last step +0.03%), so the state entering the quench is settled; only the quench
transient moves.

### What it took to get here, and what to reuse

The `J_z` leak was misdiagnosed four times — as the integrator, the z box, the
kinetic-term discretisation (predicted dealiasing would fix it; it changed
nothing), and box 35 being an outlier. Two predictions recorded in PR #177 were
wrong in opposite directions. Each time, progress came from measuring instead of
reasoning:

- `torque_budget.jl` measures each term's violation of `[H, J_z] = 0` on a real
  saved state — exactly zero in the continuum, so anything nonzero is the
  discretisation, resolved per term. Seconds, against hour-long dynamic A/B runs.
- One variable at a time, with `dx` held to the last digit (`42/288 = 35/240 =
  28/192`), separated the box from everything else.
- The final answer needed **no new run at all** — reading the existing ledgers
  along the time axis showed the efficiency was already flat.
