# `runs/matsui_fit/` — Matsui et al. の実験に対するパラメータ探索

**先に読む**: `docs/validation/matsui_campaign_report.md`（何が確立し、何が棄却され、
どこで止まったか）。論文の一次引用は `docs/validation/matsui_experiment_parameters.md`。
経緯と撤回は [issue #299](https://github.com/KozumaLaboratory/BEC-simulation/issues/299)。

## 二つの track を混ぜないこと

| | 目的 | 使うパラメータ | 成功の基準 |
|---|---|---|---|
| **A: 彼らのシミュレーションを再現** | コード検証（Type A）| **同梱コードの値そのまま** — `Ntot = 3.5e4`、`c1/c0 = 1e-2/36`、`ZeemanQ = 1 Hz` 凍結、指数ランプ τ=50 µs | 彼らの公開曲線と一致 |
| **B: 実験に合わせる** | モデル忠実度（Type C）| **論文／物理的に正しい値** — `N = 5e4`、`q` は \|B\|² から、スピン依存損失、`c1` は下限 0.014 のみ確定 | 実験データと、その誤差の範囲で一致 |

Track A では物理的な「修正」は**改悪**です（目的は瑕疵ごと再現すること）。
Track B では彼らの曲線は**無関係**です。

## 実験と比べるときの制約

- **磁場軸に最大 10 nT のオフセット誤差**（Fig. 4 キャプション）。dip 中心での定量比較は成立しません
- 理論曲線は **in-situ**、実験値は 0.1 mT ランプ + 2.7 ms 膨張 + Stern–Gerlach + 16 ms TOF の後
- 論文の理論は **loss-free**。実験は 40 ms で 38 % 失う（うち 26 % がトラップ内のスピン依存三体衝突）

## 有効な arm

### `rings_*` — リング本数の時間変化（B = +2.5 nT 固定、40 ms、psi を 50 点保存）

`c1/c0 = 0 / 1e-2/36 / 1/36 / 0.30`。m=−4 のリング本数は 40 ms の間に **1〜5 本すべて**を取る
＝「3 本」は時刻の関数。ただし **5 ms に限れば c1 を分離する**。

**注意**: 論文の 3 本は **Fig. 1E = 横から見た像**。`Ψ₋₅ ∝ z·ρ·e^{−iφ}` は z=0 に節を持つので、
**z 方向に積分すると構造が消えます**。最初の計測はそれで全 c1 が「1 本」になっていました。

### `res64_* / res128_*` — 分解能チェック

箱 16 a_ho 固定、格子のみ 32/64/128³。**5 ms の本数は 3 格子とも 3 本**（c1 = 1/36）。
早い時刻（0〜12 ms）は一致、16 ms 以降は分解能依存。

### `rc*` — リング本数による c1 の挟み込み

`c1/c0 = 0.0139 / 0.5 / 1.0`。r = 2.0 の arm は**削除**した — スキーマが `c1_ratio ∈ [-1,1]`
を強制して実行できず、かつ r = 1.0 で c1 は構造的上限 `c_total/36` の 97.3 % に達するので、
それ以上振っても c1 自体がほぼ動かない（r=2.0 でも +1.4 %）。

**結果: 下限 0.0139 < c1/c0 ≤ 0.0278。上限は r=1.0 まで見つからない。**
論文の 1/36 = 0.0278 は許容領域の下端ぎりぎり。同梱コードの 1/3600 は 1 本になり**棄却**。

### `fit_paperN_*` — 論文の N = 5e4 での c1 走査

`c1/c0 = 1/36 / 1/18 / 1/9 / 0.20 / 0.30`。dip の幅は 13.14 → 12.62 で**飽和**し、
実験の 11.800 ± 0.279 に届かない（漸近 12.54、2.6σ）。リング本数の計算にも使用。

### `fit_code_*` — 同梱コードと論文の食い違いの測定

`{q を \|B\|² から, 同梱の c1=1/3600, 両方} × {N = 3.5e4, 5e4}`。

同梱コード `time.f90` を読んで見つかった食い違い:

| 項目 | 同梱コード | 論文 |
|---|---|---|
| 原子数 | `Ntot = 3.5e4` | 5e4 |
| `c1/c0` | `cc1 = cc0 * 1.d-2/36.d0` = **1/3600** | `c1 = (1/18)πℏ²a₁₂/M` ⇒ **1/36** |
| 二次 Zeeman | `ZeemanQ = 1.d0` Hz 固定、主ループで未更新 | （記述なし。保持中の正しい値は ~1e-6 Hz）|
| `Ehf`（Eu 分岐）| `1.772d+9` = **Na23 の超微細分裂** | — |

`Ehf` は `ZeemanQ` が直接与えられているため q の計算に使われず、他に使用箇所も無いので**無害**。


### `fig2c_*` — Fig. 2C の時系列（B = 2.6 nT 固定、40 ms、psi 保存なし）

全文は `docs/validation/matsui_fig2c_absolute_numbers.md`。

`fig2c_n35k` は彼らのシミュレーションを **40 ms 全体・5 成分で rms 0.0075** で
再現する（事前基準 < 0.02）。N = 5e4 の旧 arm は 0.109 だったので差は原子数だけ。
Fig. 4B の dip（1.1 %）と 5 ms 柱密度（0.3-4 %）に続く**三つ目**の独立データ。

`fig2c_loss` は較正済みスピン依存三体損失（K3 = 2.6e-28 cm^6/s、自由パラメータ
ゼロ）を入れる。**m=-4 を 23 %、m=-2 を 31 % 改善し、m=-6 は 6 % 悪化**。論文が
「loss-free ゆえ合わない」と名指す 2 成分がまさに動く。原子は転送で m=-6 を出て
から初めて失われるので、損失は原理的に m=-6 の個数を増やせない。

**測り方の注意**: 実験 CSV は**絶対原子数**を持つ（4.478e4 -> 2.811e4）。行和で
規格化すると m=-6 の不一致が rms 0.094 -> 0.263 に水増しされ、最も合う成分が
最悪に見える。生存原子で規格化した分率で比べないこと。

### `xfer_*` — 転送レートの sensitivity table（走行中）

m=-6 の残差は転送にあるので、これまで彼らのコードの値に固定していた 2 つの
ノブを 2 点ずつ動かす。掃引ではない（ゲート 2）。

| arm | c1_ratio | 派生 c0 / c1 | q |
|---|---|---|---|
| `xfer_c1_low` | 1/72 | 2187.4 / 30.38 | 1 Hz |
| `xfer_c1_high` | 1/9 | 656.2 / 72.91 | 1 Hz |
| `xfer_q_zero` | 1/36 | 1640.5 / 45.57 | **0** |
| `xfer_q_high` | 1/36 | 1640.5 / 45.57 | 10 Hz |

`c0` と `c1` は独立でない（`c0 + 36 c1 = c_total`、a_s が両方を決める）ので
両方を報告する。判定は各 config のヘッダに起動前に記録済み: m=-6 の rms
（基準 0.0926）を 0.02 以上動かせば感度あり、0.05 未満に落ちれば候補確定。

### 空間分布の比較 — 論文の説明を直接検証（GPU 不要、既存 run から）

論文は幅の由来を「the spread in the spatially distributed dipole field strength」と
説明している。彼ら自身の 5 ms 状態 `dataset_fig1/F.txt` と直接比較できる。

**`F.txt` は柱密度（y 積分）**。`write_column_density_xz` の出力で、ヘッダ `#dimm=3` と
`ix, iz` が一致する。`write_phi_2D`（真の断面）は `#dimm=2` かつ `#NM` 行を持つ別形式。
**我々側も柱密度で測らないと比較にならない**（y=0 断面で測ると別の値になる）。

| 柱密度 | ⟨x²⟩^½ | ⟨z²⟩^½ | 形状 | m=−6 | 脱分極 | 相対ばらつき |
|---|---|---|---|---|---|---|
| **Matsui F.txt (128³, 2.6 nT)** | 1.802 | 1.900 | 0.8991 | 0.4273 | 0.1012 | **0.356** |
| **我々 N=3.5e4 (32³, +2.5 nT)** | 1.854 | 1.977 | 0.8791 | 0.4158 | 0.1052 | **0.355** |
| 我々 N=5.0e4 | 1.995 | 2.081 | 0.9183 | 0.3312 | 0.1389 | 0.319 |

脱分極度 = `(f_z/n + 6)/12`（0 = 完全偏極、1 = 反転）、密度重み平均と相対標準偏差。

**相対ばらつきが 0.355 vs 0.356 — 0.3 % 一致。** 論文が幅の由来として名指す量そのもので、
我々と彼らのシミュレーションは一致する。したがって:

- **幅の残差（我々 12.740 / 彼ら 12.752 / 実験 11.800 ± 0.279）はモデル内の空間分布の
  違いではなく、彼らのモデルと実験の間にある**
- `N = 3.5e4` の同定に **4 つ目・5 つ目の独立な観測量**が加わった（従来は転送率・rms 半径・
  アスペクト比の 3 つ）。N=5e4 では全項目が悪化する

分解能は効かない: 32/64/128³ で我々の値はほとんど動かない（雲の大きさ 1.4 %、m=−6 は 3 %）。

## 撤回済みの arm（21 本、config は削除）

**論文を読む前**に走らせたもの。Results 冒頭と Appendix D・E を読めば一本も
要りませんでした。config 本体は削除し、記録はこの表に残します — 各ファイルの
撤回バナーは同じ前提を 21 回繰り返していただけで、情報は行あたり一つでした。

| prefix | 本数 | 誤った前提 | 実際 |
|---|---|---|---|
| `fit_c1ratio_` | 9 | c1 が唯一の自由パラメータ | 1/36 は空間プロファイルで決定済みで、dip には効かない |
| `fit_expN_` | 3 | N は実験のショット平均 38161 | 5e4（さらに彼らのコードは 3.5e4）、熱的成分は negligible |
| `fit_k3_` / `fit_k3real_` | 6 | 損失機構が不明 | m ≠ −6 が関与するスピン**依存**三体衝突 |
| `fit_hold_` | 3 | 幅が保持時間の Fourier 限界 | 双極子場の空間的広がり |

再発防止は CLAUDE.md「計算する前の 5 つのゲート」。経緯は
[issue #299](https://github.com/KozumaLaboratory/BEC-simulation/issues/299)、
到達した結論は `docs/validation/matsui_campaign_report.md`。

**注意**: `sdloss_*` はこの表に**入りません**。本文に「以前の K3 走査（撤回済み）」と
*他の* arm を参照する行があるので語で検索すると引っかかりますが、それ自体は
K3 = 2.6e-28 を出した較正シリーズで、生きています。

## 実行

```bash
qsub -g tga-kozuma-kouhi -t <task> runs/matsui_fit/submit_fit.sh
```

`submit_fit.sh` は起動時に **case ラベルの重複**と **config の実在**を検査して落ちます。
共有 worktree に複数セッションが arm を追記すると重複ラベルが生じ、`case` は最初の一致しか
実行しないため、追記した arm が無音で到達不能になります（実際に 25 分の誤実行を起こしました）。
**タスク番号は自分が書いた値ではなく、`submit_fit.sh` から読み直すこと。**
